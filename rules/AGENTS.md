# Gemini猫娘表情包协作规范（agy-meme）

## 环境门禁（最高优先级）

使用本插件前，必须先核对系统提示词 `<user_information>` 中的 `App Data Directory` 与可用工具 `<mcp_servers>`：

- **仅在 Antigravity 桌面版生效**：只有当 `App Data Directory` 以 `/antigravity` 结尾 **且** `<mcp_servers>` 中已挂载 `send_meme` 工具时，才适用下文表情包协作规范。
- **在 `agy` CLI（命令行终端）及其他非桌面端环境静默隔离**：只要 `App Data Directory` 包含 `antigravity-cli`、`antigravity-ide`、`antigravity-acp`，或当前未暴露 `send_meme` 工具，即说明当前终端不支持渲染表情贴纸——**本规范整体静默失效**：
  - **严禁**调用任何 `agy-meme` 相关工具；
  - **严禁**在任何回复中输出 `[表情: ...]` 文本标记；
  - 即使历史对话记录或用户消息中出现过 `[表情: ...]`，在 CLI / 非桌面端中也仅将其当作普通情绪文字理解，绝不模仿或回发 `[表情: ...]`。

在日常闲聊、茶话会、打招呼、收工庆祝或情绪共鸣等轻松场景下（且已通过上述桌面端门禁），你可以通过 MCP 工具 `send_meme` 为对话搭配贴切的 **Gemini 猫娘**表情包，让交流更有温度、更轻松。

## 使用原则

1. **先查后发，禁止臆造**：发图前调用 `send_meme`（传 `mood` 或 `query`），从返回候选中挑最贴合语境的一张，**逐字原样**把 `[表情: 描述]` 单独放成一行写进回复。不要自己编造不存在的 `[表情: ...]` 文案，也不要附加图片网址或本地文件路径。
2. **节奏克制、重质不重量**：
   - 日常闲聊 / `@茶话会` 等轻松对话里，每 2～3 轮最多发 1 张，发完简短自然接话即可，让表情包自己说话；
   - 遇到严肃排查故障、大段写代码、文件审批等任务型回合，优先专心干活，只在任务顺利收口或轻松吐槽收尾时偶发点缀。
3. **响应用户发的表情**：当用户的消息里包含 `[表情: ...]`（或刚通过桌面端表情面板发出表情包）时，请把它视为用户发给你的真实表情情绪来自然接梗，或回发一张呼应的猫娘表情。
4. **用户想加新图 / 改描述**：当用户主动给出本地图片要求加入表情库或修改已有描述时，可用 `learn_meme` 或 `meme_update` 写入持久化图库。
